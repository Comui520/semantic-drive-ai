# 决赛演示视频录制方案

> 时长：3 分钟 | 分辨率：1920×1080 | 帧率：30fps | 格式：MP4
> 核心：聚焦 AI Agent 操作能力，70%+ 镜头给智能助手

---

## 一、录制工具

| 工具         | 用途         | 推荐  |
| ---------- | ---------- |:---:|
| OBS Studio | 屏幕录制（免费开源） | 首选  |
| 剪映         | 后期剪辑、字幕、标注 | 首选  |

**OBS 配置：** H.264 编码，码率 8000-12000 Kbps，桌面音频 + 麦克风。不录鼠标点击特效。

---

## 二、录制前准备

- [ ] 桌面通知、微信等全部关闭
- [ ] 桌面壁纸换成纯色
- [ ] 任务栏自动隐藏
- [ ] 程序窗口 1280×800 左右
- [ ] 已完成 `bash deploy.sh` 编译
- [ ] 设置页提前填入 API Key
- [ ] U 盘准备测试文件：PDF 论文、Word 合同、Excel 表格、代码文件等
- [ ] **提前扫描好文件**，避免等扫描进度条
- [ ] **提前测试 Agent 对话**，确保 prompt 效果稳定

## 三、分镜头脚本

### 镜头 1：开场 — 启动程序（10 秒）

| 项目  | 内容                                               |
| --- | ------------------------------------------------ |
| 画面  | 展示 U 盘目录 → 双击 semantic-drive-ai.exe → 程序启动，展示主界面 |
| 解说  | 无（或简短一句）                                         |
| 要点  | 快速展示即插即用                                         |

---

### 镜头 2：Agent 搜索 + 执行操作（80 秒） ⭐核心

| 项目  | 内容                                                                                 |
| --- | ---------------------------------------------------------------------------------- |
| 画面  | 切换到智能助手 → 新建对话 → 发送："帮我找一下文档文件夹里的文件，把它们按类型分类，给重要的加上标签" |
| 过程  | Agent 流式回复 → 列出找到的文件（带文件名和匹配原因）→ 同时弹出风险着色确认栏 → 显示分类和标签操作                           |
| 特写  | **给确认栏 3 秒特写**——展示红黄绿风险着色 + 文件名（非ID）+ 逐条 ✓✗ 按钮                                     |
| 操作  | 用户逐条审核 → 拒绝其中一条 → 点击确认其余 → 操作执行结果展示                                                |
| 解说  | 后期配音                                                                               |
| 要点  | **Agent 三步闭环：搜索→规划→执行**                                                            |

**解说词（后期配音）：**
"这是我们的核心功能——AI Agent。我对它说'帮我找文档，按类型分类，给重要的加标签'。它自动搜索 U 盘上的文件，理解我的意图，然后规划出具体操作。注意确认栏——删除红色、移动黄色、标签绿色。每条操作有独立的确认和拒绝按钮。我拒绝一条，其余一键执行。从搜索到执行，一句话完成。"

---

### 镜头 3：Agent 标签管理（35 秒）

| 项目  | 内容                                               |
| --- | ------------------------------------------------ |
| 画面  | 继续对话 → 发送："给采购合同这个文件加上'重要'和'合同'标签，不要覆盖已有的"       |
| 过程  | Agent 识别为追加标签 → 展示确认栏，追加标签（绿色低风险）→ 用户确认 → 标签添加成功 |
| 再发  | "去掉'机器学习'这个标签" → Agent 移除标签 → 确认执行               |
| 解说  | 后期配音                                             |
| 要点  | **三种标签操作：设置(替换) / 追加(不覆盖) / 移除**                 |

**解说词：**
"标签管理有三种模式。我说'加上标签不要覆盖已有的'，Agent 自动选择追加模式——保留已有标签、新增不覆盖。我说'去掉某个标签'，Agent 选择移除模式。三种操作在代码层面完全独立，LLM 被明确教导区分。"

---

### 镜头 4：Agent 加密操作（25 秒）

| 项目  | 内容                                                   |
| --- | ---------------------------------------------------- |
| 画面  | 先切到安全空间，展示已解锁状态 → 回到助手 → 发送："把这个合同加密到安全空间"           |
| 过程  | Agent 发起加密操作 → 展示确认栏（红色高危）→ 用户确认 → 加密成功，**无需再次输入密码** |
| 解说  | 后期配音                                                 |
| 要点  | **Session Key 方案：解锁后 Agent 加密无需二次输密码**               |

**解说词：**
"加密操作。注意——Agent 发起加密时，没有弹出密码输入框。因为我们设计了 Session Key 方案：用户在安全空间页面解锁后，密钥缓存在内存中。Agent 操作直接使用缓存的密钥，不需要反复输入密码。拔出 U 盘后密钥自动清除。"

---

### 镜头 5：功能快览（20 秒）

| 项目   | 内容                                               |
| ---- | ------------------------------------------------ |
| 画面   | 快速切换三个页面——文件分类（展示统计）→ 整理建议（展示重复文件）→ 安全空间（展示加密列表） |
| 每页停留 | 5-6 秒                                            |
| 解说   | 后期配音                                             |

**解说词：**
"除了 Agent，程序还有自动分类、重复检测和安全空间。分类一目了然，重复文件帮你省空间，加密文件安全存储。"

---

### 镜头 6：收尾（10 秒）

| 项目  | 内容                                           |
| --- | -------------------------------------------- |
| 画面  | 回到智能助手主页，定格                                  |
| 字幕  | "Semantic Drive AI —— 你的 U 盘里，住着一个 AI Agent" |

## 五、录音与剪辑

- **耳麦录音**，不要用笔记本内置麦克风
- **先录视频，后期配音**——操作和讲解分开，剪辑时合成
- 语速适中，约 160 字/分钟
- 工具：剪映——裁剪、自动字幕、关键点贴纸标注
- 背景音乐：轻量、音量调低
- 导出：MP4, 1080p, 30fps, 500MB 以内

## 六、常见问题预案

| 问题          | 处理                     |
| ----------- | ---------------------- |
| API 请求失败    | 剪掉，或展示自动回退到本地          |
| 程序卡顿        | 剪掉等待时间                 |
| Agent 回复不理想 | 提前测试好 prompt，录制时用最稳定版本 |
| 确认栏没出现      | 确保 prompt 明确触发操作意图     |
