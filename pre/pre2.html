Smart Search

语义搜索：AI 理解你的意图

BGE 嵌入模型将查询和文件映射到同一语义空间

工作流程
输入"上个月的PPT" → BGE 转为 512 维向量 → 与所有文件向量计算余弦相似度 → FTS5 关键词评分加权 → 返回混合排序结果
三种搜索模式
语义搜索：自然语言理解，找"去年的财务报表"=> 匹配内容含义
关键词搜索：FTS5 全文索引，毫秒级精确匹配
混合搜索：两者加权联合排序，结果更精准
核心优势
即使文件名不含关键词，也能通过内容语义匹配到正确文件

Security

安全空间：文件级加密保护

AES-256-GCM + Argon2id，军用级加密

加密方式
每个文件独立加密，AES-256-GCM 认证加密算法，密钥由 Argon2id 密码派生函数生成
使用流程
设置密码 → 拖入文件自动加密 → 输入密码解密查看 → 拔出 U 盘即安全锁定
隐私保障
加密密钥仅存在于内存中，关闭应用或拔出设备后自动清除

Offline AI

全离线 AI 架构

所有模型本地运行，无需联网，保护隐私

推理框架：Candle
纯 Rust ML 推理框架，零 Python 依赖，无需 CUDA，CPU 可运行。使用 GGUF 格式量化模型，文件体积小、加载快
Qwen2.5 GGUF 对话模型
国产通义千问 2.5 量化版，Q4_K_M 精度约 700MB。支持流式生成、意图识别、RAG 文件上下文
BGE-small-zh 嵌入模型
BAAI 中文语义向量模型，512 维输出。支持中英双语，用于语义搜索和分类的特征提取

Privacy by Design

隐私安全设计原则

用户数据永不离开设备，隐私从架构上保障

零网络请求
所有 AI 推理在本地 CPU 完成，没有任何数据上传到云端。即使用于敏感文件也无需担心泄露
非破坏性架构
运行期间仅创建 .semanticdrive 缓存目录存储索引和向量，永不修改用户的原始文件
即拔即走
所有数据和应用都在 U 盘上，拔出后电脑不留任何痕迹。真正即插即用、即拔即走
AES-256-GCM 加密
安全空间采用认证加密算法，Argon2id 抗 GPU 暴力破解，密钥仅存于内存

Performance
